작가의 그림과 소리를 여기에 넣습니다. 저장소에는 올라가지 않습니다.

```bash
python3 make_art.py      # 목록(art.json)을 다시 만든다. ./start.sh 가 켤 때마다 대신 해 준다
```

## 그림

- 배경이 비치는 PNG 로 저장합니다. 한 장에 하나씩, 긴 쪽 800픽셀이면 넉넉합니다.
- 쌓이는 순서는 파일 이름 순서입니다. `01-나무.png`, `02-새.png` 처럼 앞에 번호를 붙입니다.
- 이름이 `alien` 으로 시작하는 그림은 외계인의 그림으로 따로 모읍니다.

## 소리

- 8초에서 16초 사이의 루프로 만듭니다. 답할 때마다 한 겹씩 겹쳐 쌓입니다.
- 서로 부딪히지 않게 음이 적은 것이 낫습니다. 파일 이름 순서대로 쌓입니다.
- 소리가 없으면 맑은 음 하나가 대신 납니다. 5음 음계라 몇 겹이 쌓여도 부딪히지 않습니다.
